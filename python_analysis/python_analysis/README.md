# Python Data Analysis

This folder contains Python-based data analysis
performed on the Uber Ride Booking dataset.

## Libraries Used

- Pandas
- NumPy
- Matplotlib

## 1. Pandas
Used for:
- Data loading
- Data cleaning
- Missing value handling
- Data manipulation
- GroupBy operations
- Aggregation
- Pivot tables

## 2. NumPy
Used for:
- Numerical calculations
- Statistical operations
- Array manipulation
- Mathematical operations

## 3. Matplotlib
Used for:
- Booking trend visualization
- Vehicle analysis
- Revenue visualization
- Cancellation analysis
- Customer rating visualization

## Objective

To analyze ride booking data and extract
meaningful business insights using Python.
